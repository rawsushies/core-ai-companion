# COre 10.0.0

COre is a desktop companion made of glowing smoke. It talks, listens, gestures, shape-shifts, multitasks
with helper copies, and runs on your own Claude Code login (no API key).

## Highlights
- **Real Windows app**: installer with shortcuts and an uninstaller, a full Settings window, start with
  Windows, automatic updates.
- **Body language**: 30 smoke gestures with moving fingers, chosen as COre talks.
- **Shape-shifting**: the smoke forms emoji, symbols and text, with a giggle, hum, sigh or ding to match.
- **Presence**: polite idle chit-chat, reactions to petting, tickling, poking and tossing, plus trivia,
  riddles and 20 questions.
- **Many COres**: up to 3 helper copies work in parallel. Each has its own colour, voice and context; they
  never overlap on screen and never talk over each other.
- **Hands-free**: an on-device "Hey COre" wake phrase, barge-in, hold-to-talk and conversation mode.
- **Screen partner**: notices error pop-ups and offers to look, points accurately and follows you across monitors.
- **Skills**: notes, timers, weather, music control, app launcher, web search, calendar, and JSON plugins.
- **Polish**: themes, performance profiles, reply language, accessibility options, local crash logs and a
  first-run tour.

## Privacy
Speech recognition, the voice and the wake phrase run on your PC. Screenshots are taken only when you ask
or click. Skills never run commands made from the model's words. Crash logs stay local.

## Upgrading
Installed copies update themselves; source copies update from `main`. Your settings, memory and notes are kept.
