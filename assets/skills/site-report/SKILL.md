---
name: site-report
description: Summarise a building model or drawing (IFC, DXF) for a site or design review.
triggers: site report, model summary, bim summary, drawing summary
core: archivist
enabled: true
---

Use the attached IFC or DXF file.

- **Model**: project name, schema or CAD version, units if known.
- **Levels**: storeys with elevations, in order.
- **Elements**: counts of walls, slabs, doors, windows, columns, beams, stairs; call out anything unusual (e.g. many proxy elements, missing storeys).
- **Spaces and materials**, if present.
- **Checks**: three things a reviewer should verify on site or in the model.

State clearly that counts come from the file and were not measured.
