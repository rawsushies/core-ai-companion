Use the attached recording or transcript (drop the file first).

1. One line: what the meeting was about and who spoke, if names are clear.
2. **Decisions**: each as one sentence.
3. **Action items**: a table with task, owner and due date. Write "?" when the owner or date was not said; never guess.
4. **Open questions**: anything left unresolved.
5. Offer to set reminders for the dated items (use the remind tag only if the user says yes).

Keep it short. Quote numbers exactly as said.
