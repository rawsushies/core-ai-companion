# COre benchmarks

Generated by `node scripts/benchmark.js --out docs/BENCHMARKS.md` on 2026-11-12 (linux, Node 22.23.4).
Real components only: COre memory, the real Cortex MCP server, the real OS sandbox, the injection guard and the local decision layer.
Injection guard sets: the tuning set and held-out set #1 were both used when patterns were changed; held-out set #2 was written before the second round of changes (it scored 0/6 then) and has now influenced it too. The "fresh, untuned" set was written after the last pattern change and has not been used to change anything: it is the unbiased number.
Not measured here: AI provider answer quality and Jev remote decisions (no provider access in the build environment). Desktop task completion on real Windows is covered by the CI acceptance tests (`test/agent.win.test.js`, `test/situation.win.test.js`).
